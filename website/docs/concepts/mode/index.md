# Mode

Web HUD 에서 에이전트와 일하는 방식을 상황에 맞게 바꾸는 모드전환 시스템을 소개한다. 모드는 말로 주고받는 방식을 정하는 음성 축과, 화면과 에이전트가 무엇에 집중할지를 정하는 작업 축으로 나뉜다. 두 축은 따로 고르고 겹쳐 쓸 수 있어서, Full-voice 로 Focus 작업을 하는 조합도 가능하다.

## 개요

같은 사용자라도 상황마다 에이전트와 소통하고 싶은 방식이 다르다. 책상 앞에서는 답을 화면으로 읽는 편이 빠르고, 손이 바쁠 때는 말로 묻고 들어야 한다. 긴 작업 하나에 매달릴 때는 대화 목록보다 분석, 조사, 기록, 진행률이 한 화면에 보이는 편이 낫다. 기존의 Chatbot Assistant는 대개 음성 모드와 작업 화면을 하나의 스위치로 묶어 두기 때문에, "말로 하면서 작업에 집중" 하는 조합을 고를 수 없다. Jarvis-Agent의 Mode는 이러한 부분에서 착안하여 음성과 작업을 서로 독립된 두 축으로 나누고, 사용자가 필요한 조합을 직접 고르게 한다.

> 음성 축(Default / Full-voice) + 작업 축(Focus)

음성 축의 기본값인 Default 에서는 응답을 화면으로 보고, 구체를 눌러 말로 한 요청만 소리로 읽어 준다. 헤더의 `FULL-VOICE` 로 바꾸면 응답, 승인 요청, 먼저 건네는 말까지 모두 말로 묻고 답한다. 작업 축은 `/focus <작업>` 이나 음성 `포커스 모드 <작업>` 으로 켜며, 작업 하나에 보조 sub-agent 를 붙이고 화면을 작업 중심으로 바꾼다.

### 같이 쓸 때

두 축은 서로의 상태를 건드리지 않는다. 그래서 한쪽을 켜고 끄는 일이 다른 쪽의 설정을 바꾸지 않도록 아래 규칙을 지킨다.

- Focus 중에도 음성 모드는 헤더에서 그대로 바꾼다. 헤더의 `FOCUS` 표시는 음성 모드와 따로 붙는다
- 음성으로 시작한 요청이면 Default 에서도 승인을 음성으로 묻는다. Focus 중이어도 같다
- Focus 를 끝내도 음성 모드는 바뀌지 않는다

### 기능 목록

| 페이지 | 축 | 켜는 법 | 다루는 것 |
|---|---|---|---|
| [Focus Mode](./focus-mode.md) | 작업 | `/focus <작업>`, 음성 `포커스 모드 <작업>` | sub-agent 넷(분석, 조사, 기록, 진행), 턴 훅, 화면 네 영역, 기록 파일과 재시작 복구 |
