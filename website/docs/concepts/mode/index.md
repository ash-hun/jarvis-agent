# Mode

Web HUD 에서 에이전트와 일하는 방식을 상황에 맞게 바꾸는 모드전환 시스템을 소개한다. 지금 모드는 화면과 에이전트가 작업 하나에 집중하게 하는 Focus 하나다. 음성에는 따로 고르는 모드가 없고, 말로 시작하면 그대로 말로 이어 간다.

## 개요

같은 사용자라도 상황마다 에이전트와 소통하고 싶은 방식이 다르다. 책상 앞에서는 답을 화면으로 읽는 편이 빠르고, 손이 바쁠 때는 말로 묻고 들어야 한다. 긴 작업 하나에 매달릴 때는 대화 목록보다 분석, 조사, 기록, 진행률이 한 화면에 보이는 편이 낫다. Jarvis-Agent는 말로 할지 글로 할지는 사용자가 시작한 방식으로 정하고, 작업에 집중할지는 Focus 로 따로 켜게 한다. 그래서 스위치를 바꾸지 않고도 "말로 하면서 작업에 집중" 할 수 있다.

타이핑한 요청은 화면으로만 답한다. 구체 클릭, "Jarvis" 웨이크워드, 데스크톱 전역 단축키로 말해서 시작하면 답을 읽어 준 뒤 다시 들으며 대화를 이어 가고, 말이 없거나, 타이핑하거나, 읽기를 멈추면 끝난다([말로 이어 가는 대화](../conversation/voice.md#말로-이어-가는-대화)). Focus 는 `/focus <작업>` 이나 음성 `포커스 모드 <작업>` 으로 켜며, 작업 하나에 보조 sub-agent 를 붙이고 화면을 작업 중심으로 바꾼다.

### 같이 쓸 때

Focus 와 음성 대화는 서로의 상태를 건드리지 않는다.

- Focus 중에도 말로 시작하면 대화가 열리고, 타이핑하면 화면으로만 답한다
- 말로 시작한 요청이면 Focus 중이어도 승인을 음성으로 묻는다
- 말로 Focus 를 켜고 끄면 음성 대화는 그대로 이어진다
