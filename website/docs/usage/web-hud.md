# Web HUD 사용법

`docker compose --profile web up -d` 또는 `jarvis --web` 뒤 http://localhost:7777. 정적 HTML 과 ES 모듈(`src/jarvis/ui/web/static/`)을 nginx 가 서빙하고, `/api/*` 와 `/ws` 만 백엔드로 간다. 화면은 하나고 세션 전환은 WebSocket 재연결이다. 정본은 레포의 `docs/screen-spec.md`.

## 화면

```text
┌──────────────────────────────────────────────────────────────┐
│ SYS:ONLINE / 버전      J.A.R.V.I.S.          READY  HH:MM:SS  │ 헤더
├───────────────┬──────────────────────────┬───────────────────┤
│ AGENDA        │                          │ SESSIONS          │
│  UPCOMING     │        리액터(구체)       │  default  NOW ⑂   │
│  OPEN LOOPS   │                          │                   │
├───────────────┤       ● ACTIVE           ├───────────────────┤
│ ACTIVITY      │       "명언" / 마지막 줄  │ CONVERSATION      │
├───────────────┤                          │  USER / J.A.R.V.I.S│
│ SYSTEM        │                          │  💭  🔔  SYS      │
│  MODEL…COST   │                          │                   │
│  TOOLS ▾      │                          │                   │
├───────────────┴──────────────────────────┴───────────────────┤
│ >_ [입력창                              ]  [SEND ⏎]          │ 입력 독
└──────────────────────────────────────────────────────────────┘
```

| 영역 | 내용 |
|---|---|
| 헤더 | 연결 상태, 브랜드 이름, 상태 pill(`READY`, `THINKING`, `EXECUTING`, `LISTENING`, `SPEAKING`, `ERROR`), 시계 |
| AGENDA | 예정 작업(스위치로 켜고 끄기)과 open loop(✓ done, ✕ dismiss). 접속, 사고, 턴 끝, 조작 직후, 1분마다 갱신 |
| ACTIVITY | 도구 시작과 끝, 승인, 💭, 🔔, 세션 전환, 오류, 서브 에이전트(`↳ name`) 로그. 최소 높이를 지킨다 |
| SYSTEM | 가동 시간, 모델, 세션, 토큰(In, Out, Cache), 비용, 최근 16턴 사용량 그래프, TOOLS 목록(🔒 는 승인 필요) |
| 리액터 | 상태가 구체와 링에 보인다. 대기는 천천히 돌고, 생각은 빨라지고, 실행은 눈금이 켜진다. 아래 캡션은 명언 또는 마지막 한 줄. 클릭하면 음성 모드 |
| SESSIONS | `+` 새 세션, 이름 클릭으로 전환, 활성 세션의 ⑂ 분기, 비활성 세션에 마우스를 올리면 ✕ 삭제 |
| CONVERSATION | USER, 응답(마크다운), 💭(접힘, 클릭하면 해석 전문), 💬 filler, 🔔, 도구 흔적, THINKING 자리표시, 복원된 히스토리 |

열 안은 세로 flex 다. SESSIONS 와 CONVERSATION 헤더를 클릭하면 접히고 아래 카드가 자리를 채운다(접힘 상태는 localStorage). 860px 이하에서는 왼쪽 열이 드로어가 되고 헤더의 ≡ 로 연다.

## 입력

- Enter 또는 SEND. 입력이 잠기고 THINKING 자리표시가 뜬다. 첫 이벤트가 오면 스트리밍 메시지로 바뀐다. 90초 안에 아무 이벤트가 없으면 자리표시를 지우고 READY 로
- `/` 로 시작하면 자동완성 팝업. ↑↓ 이동, Enter 또는 Tab 선택, Esc 닫기. 문장 중간의 `/명령` 도 하이라이트된다
- `Ctrl+K` 중단. 스트림을 끝내고 입력을 돌려준다
- 8줄 이상 코드블록이 응답에 있으면 오른쪽 아티팩트 패널에 뜬다(COPY, ✕). 코드블록마다 COPY 버튼
- 입력은 한 줄이다. 줄바꿈은 없다

## 승인

승인이 필요한 도구가 불리면 모달이 뜬다. `ALLOW`(이번만), `ALWAYS · 패턴`(규칙으로 저장, 서버가 패턴을 제안했을 때만 보임), `DENY`. Enter 는 ALLOW. 같은 세션을 여러 탭에서 보고 있으면 모두 모달을 받고, 하나가 답하면 나머지는 닫히며 ACTIVITY 에 "다른 창에서 처리됨" 이 남는다. 120초 무응답은 거부.

## 🔔 와 피드백

🔔 아래에 "도움이 됐나요?" 가 붙는다. 다음 입력이 `네`, `좋아`, `고마워`, `아니오`, `됐어`, `무시` 같은 짧은 답이면 피드백으로만 쓰이고 LLM 에 가지 않는다. 다른 말을 하면 보통 메시지로 흘러가고 질문은 닫힌다. 음성 모드면 🔔 를 읽어 주고 같은 방식으로 답한다.

## 세션

- `+` 로 새 세션. 이름 클릭으로 전환하면 대화, 사용량, 아티팩트가 초기화되고 히스토리가 복원된다
- ⑂ 는 활성 세션 분기. Postgres 저장소에서는 빈 새 세션이 만들어진다
- ✕ 는 보고 있지 않은 세션만. 확인 뒤 지우고, 되돌릴 수 없다

## 접근 키

`JARVIS_SECURITY__API_KEYS` 가 설정돼 있으면 첫 연결이 4401 로 끊기고 브라우저가 키를 한 번 묻는다. 키는 localStorage 에 저장된다. 취소하면 상단 배너와 ACTIVITY 에 "접근 키 없음".

## 끊김과 복구

WS 가 끊기면 상단 배너 "연결 끊김 — 재연결 중", 입력 잠금, 1초부터 2배씩 최대 10초 간격으로 재접속. `agent_error` 와 `error` 는 SYS 메시지와 상태 ERROR 3초. AGENDA 나 TOOLS 요청 실패는 콘솔 경고만.

## PWA 와 캐시

서비스 워커가 셸 파일을 네트워크 우선으로 받고 끊겼을 때만 캐시를 쓴다. 버전 문자열이 없으므로 파일을 고치면 새로고침으로 반영된다. `manifest.json` 과 아이콘이 있어 홈 화면에 추가할 수 있다. 브랜드 이름과 색은 `/brand.js` 로 내려온다.

## 자동과 수동 검증

- 수동 시나리오 3개(성찰과 🔔 와 피드백, 승인 기억, 절차 학습): `scripts/e2e/hud-scenario.md`
- 자동 e2e: `uv run python scripts/e2e/launch_hud.py &` 로 스크립트 프로바이더 HUD 를 7799 에 띄우고 `uv run --with playwright python scripts/e2e/hud_flow.py`
