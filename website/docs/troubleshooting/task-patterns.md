# 작업 패턴

알려 준 작업 방식을 에이전트가 다음에 따르지 않거나, 다른 에이전트가 모르거나, 엉뚱한 요청에 적용한다.

## 확인 순서

1. 그 에이전트의 세션에서 `/patterns` 로 작업 패턴이 저장됐는지 본다.
2. 저장됐다면 다른 에이전트 세션에서 기대한 것은 아닌지, 키워드가 너무 흔한 말은 아닌지 본다.

## 원인과 해결

- "기억하겠습니다" 라고 했는데 다음에 안 따름: `/patterns` 에 없으면 모델이 저장 도구를 부르지 않은 것이다. "remember_task_pattern 으로 저장해" 처럼 도구 이름을 짚어 말하면 모델이 도구를 부를 가능성이 높다. 저장됐는지는 `/patterns` 로 다시 확인한다
- 다른 에이전트가 모름: 작업 패턴은 저장한 에이전트만 쓴다. 다른 에이전트에도 필요하면 그 에이전트 세션에서 같은 방식을 알려 준다
- 엉뚱한 요청에 패턴이 붙음: 키워드가 너무 흔한 말이라서 그렇다. `/patterns forget <이름>` 으로 지우고 더 좁은 키워드로 다시 알려 준다
