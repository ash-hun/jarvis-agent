# 화면이 옛날 것이다

화면 파일을 고쳤거나 새 버전으로 올렸는데 브라우저에 옛 화면이 보인다.

## 확인 순서

1. 새로고침한다. 정적 파일은 네트워크 우선으로 받으므로 대개 이것으로 반영된다.
2. 그래도 옛 화면이면 브라우저 개발자 도구의 Application 탭에서 서비스 워커를 지우고 다시 연다.

## 원인과 해결

서비스 워커는 연결이 끊겼을 때만 캐시를 쓰고, nginx 와 백엔드는 모두 `Cache-Control: no-cache` 를 붙인다. 새로고침으로 반영되지 않는다면 브라우저에 남은 옛 서비스 워커가 원인이므로 위 두 번째 단계로 지운다.
